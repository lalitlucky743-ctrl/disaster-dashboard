## ✨ Features

- 🗺️ **Interactive Map** – View disaster events by location
- 🌪️ **Multiple Disaster Types** – Earthquakes, floods, storms, wildfires, and more
- 📈 **Charts & Analytics** – Trends, severity, and frequency at a glance
- 🔍 **Search & Filters** – Filter by type, region, date, and severity
- ⏱️ **Real-Time Updates** – Stay informed with fresh data
- 📱 **Responsive Design** – Works on desktop, tablet, and mobile
- 🌙 **Clean, Modern UI** – Easy to read in emergencies

## 🚀 Getting Started

### ✅ Prerequisites

- 🟢 [Node.js](https://nodejs.org/) (v18 or higher) and npm
- 🔧 [Git](https://git-scm.com/)

### 📥 1. Clone the Repository

```bash
git clone https://github.com/lalitlucky743-ctrl/disaster-dashboard.git
cd disaster-dashboard
```

### ⚙️ 2. Set Up the Backend

```bash
cd backend
npm install
npm start
```

### 🎨 3. Set Up the Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

### 🌐 4. Open in Browser

Visit `http://localhost:5173` (or the port shown in your terminal). 🎉

> 📝 *Adjust the commands above if your project uses a different stack or scripts.*

## ⚙️ Environment Variables

Create a `.env` file inside the `backend/` (and `frontend/` if needed):

```env
# 🔑 Example values - replace with your own
PORT=5000
API_KEY=your_api_key_here
DATABASE_URL=your_database_url_here
```

⚠️ **Never commit your `.env` file or API keys to GitHub.**

## 🌐 Deployment

The frontend is deployed on **Vercel** ▲.

1. 🔗 Import the repository on [Vercel](https://vercel.com/)
2. 📂 Set the root directory to `frontend`
3. 🔐 Add any required environment variables
4. 🚀 Click **Deploy**
